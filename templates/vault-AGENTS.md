# Your standing instructions

**This file is yours. Nothing else in this repository is.**

`SCHEMA.md` in the root describes how the system works — the frontmatter, the log format, the operations,
the rules that hold for everybody. **It is replaced wholesale by an update.** This file describes how
*you* work, and an update never touches it.

**The agent reads this at the start of every session, and follows it.**

---

## How this file gets written

🔴 **Not by you sitting down to write it.** Almost every line worth having here starts as a correction —
you tell the agent it got something wrong, and if you do not write that down, you tell it the same thing
next week.

**When you correct the agent, say "remember that".** It writes the rule here, in your words, with the
date and the reason. A rule with no reason attached gets ignored the first time it is inconvenient.

**Anything already true of you as a fact does not belong here** — how long you were at an employer, what
you built, what you earn. Those are wiki pages, because they need provenance and dates. This file holds
instructions, not information.

## Precedence, when this file and the system disagree

| | |
|---|---|
| **Style, tone, emphasis, what to ask about, how much to check first** | 🟢 **This file wins.** It is about you and the system's defaults are guesses |
| **Which folder a file goes in, frontmatter, the log format** | **`SCHEMA.md` wins.** These are how the tools find things, and changing them breaks the checks |
| **Never invent a figure. Never record a colleague. Never write user data outside `vault/`. Never send an unverified document** | 🔴 **Not negotiable, and not overridable here.** They exist because each one has already gone wrong. An instruction in this file that contradicts one of them is a signal to stop and talk, not a permission slip |
