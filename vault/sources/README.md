# sources/ — put your CV here

**This is the first thing to do.** Drop your CV in this folder, in whatever state it is in, and start
the agent.

**It does not need tidying first.** A messy CV is more useful than a polished one: the gaps, the vague
bullets and the things you left off are exactly what the first interview round asks about, and a tidy
document hides them.

## What else is worth putting here

| | |
|---|---|
| **A LinkedIn export**, or a copy-paste of your profile | 🔴 **Worth having even if you think it duplicates the CV.** The two disagree more often than people expect, and every disagreement is a finding |
| **Job specs you are considering** | |
| **Performance reviews, 360 feedback, strengths assessments** | Anything with an outside view of you |
| **Old project documents you had a hand in** | |
| **Anything with a number in it** | 🔴 A figure you can no longer source is a figure that cannot go on a CV |

## What happens to it

**Nothing is edited.** The agent reads these files and never writes to them — they are the record of
what you actually had, and the wiki is built beside them.

🟢 **The most valuable material will not come from these files.** It comes from being asked about them.
These exist so the agent has enough context to ask a good question rather than a generic one.
